# ai-day-calculator
A funny AI-based day calculator built with Python Flask, HTML and CSS.
1️: Clone the repository
git clone https://github.com/udaysingh3/ai-day-calculator.git
2️: Go to the project folder
cd ai-day-calculator
3️: Install Flask
pip install flask
4️: Run the Python app
python app.py
5️: Open in browser

Open your browser and go to:

http://127.0.0.1:5000

Now enter a day and the AI will calculate the next day 🎉
